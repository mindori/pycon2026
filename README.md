## 🚀 처음이신가요? 여기부터

**파이썬을 미리 설치하지 않으셔도 됩니다.** 아래 1번에서 설치할 `uv`라는 도구가
알아서 받아옵니다. 전부 합쳐 **10분**이면 끝납니다.

### 1. 터미널 열기

| | |
|---|---|
| **맥** | `Command` + `Space` → "터미널" 입력 → `Enter` |
| **윈도우** | 시작 메뉴에서 "PowerShell" 검색 → 실행 |
| **리눅스** | `Ctrl` + `Alt` + `T` |

까만 창이 하나 뜨고 커서가 깜빡이면 준비된 것입니다. 여기에 아래 명령들을
한 줄씩 복사해 붙여넣고 `Enter`를 누르시면 됩니다.

### 2. uv 설치하기

`uv`는 파이썬 프로젝트를 관리해주는 도구입니다. **파이썬 자체도 이 도구가
설치해 줍니다.**

**맥 / 리눅스**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**윈도우 (PowerShell)**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

설치가 끝나면 **터미널을 완전히 닫았다가 다시 열어 주세요.** 그래야 `uv` 명령을
찾을 수 있습니다. 다시 열고 아래를 실행해 버전이 나오면 성공입니다.

```bash
uv --version
```

> ❌ `command not found: uv` 가 나온다면 터미널을 아직 다시 열지 않으신
> 겁니다. 창을 닫고 새로 열어 보세요.

### 3. 이 저장소 내려받기

```bash
git clone https://github.com/mindori/pycon2026.git
cd pycon2026
```

> `git`이 없다는 메시지가 나오면, 이 페이지 위쪽 초록색 **Code** 버튼 →
> **Download ZIP** 으로 받아 압축을 푸셔도 됩니다. 이 경우 폴더 이름이
> `pycon2026-main` 이 되므로 `cd pycon2026-main` 으로 들어가세요.

### 4. 필요한 것 설치하기 — 파이썬 포함

```bash
uv sync
```

이 한 줄이 **파이썬 3.11과 필요한 라이브러리를 전부** 받아옵니다. 컴퓨터에 이미
있는 파이썬을 건드리지 않고, 이 폴더 안에만 따로 설치하니 안심하셔도 됩니다.
처음 실행할 땐 1~2분 걸릴 수 있습니다.

### 5. API 키 넣기

Google Gemini API 키가 필요합니다. **무료이고 신용카드 등록이 필요 없습니다.**

발급 방법은 **[API 키 발급 가이드](docs/prework/01-api-key.md)** 를 그대로
따라오시면 됩니다 (5분).

키를 받으셨으면:

```bash
cp .env.example .env
```

그리고 만들어진 `.env` 파일을 편집기로 열어 발급받은 키를 붙여넣으세요.

```
GOOGLE_API_KEY=여기에_발급받은_키를_붙여넣으세요
```

### 6. 잘 됐는지 확인하기

```bash
uv run python check_env.py
```

✅ 가 다섯 개 나오면 준비 끝입니다. ❌ 가 있으면 **화면에 무엇을 해야 하는지
함께 나옵니다.** 그대로 따라 하시면 됩니다.

### 7. 실행해 보기

```bash
uv run python main.py
```

`receipts/` 폴더에 들어 있는 샘플 영수증으로 전 과정이 돌아갑니다. AI 둘이
토론하고 마지막에 점수가 나오면 성공입니다.

## 준비물

- **노트북** (맥 / 윈도우 / 리눅스 무관)
- **Google Gemini API 키** — 무료, 신용카드 불필요
- **본인 영수증 3~5장** (선택)

> 💡 **품목이 찍힌 영수증**이 좋습니다. 편의점·카페·마트 영수증처럼 무엇을
> 샀는지 줄줄이 적힌 것이요. 카드 결제 전표(가맹점명과 승인금액만 있는 종이)만
> 있으면 AI가 "어디서 얼마"까지만 알 수 있어 토론이 심심해집니다.
>
> 감열지 영수증은 시간이 지나면 글자가 날아갑니다. **받는 즉시 사진으로
> 찍어두세요.** 없어도 괜찮습니다 — 샘플이 들어 있습니다.

## 무엇을 배우나요

| 단계 | 배우는 것 |
|---|---|
| **본다** | Vision LLM으로 영수증을 읽고, Pydantic **구조화 출력**으로 들쭉날쭉한 LLM을 안정적인 함수처럼 다루는 법 |
| **정리한다** | 카테고리별 집계. LLM 없이 순수 파이썬으로 |
| **토론한다** | **페르소나 프롬프트 설계**, 그리고 초급자가 가장 자주 빠지는 **멀티에이전트 무한 루프를 막는 종료 조건 설계** |
| **판정한다** | 판정관 AI가 토론을 종합해 재무 건강 점수와 처방전을 내놓기 |

수료 후 **멀티모달 입력 → 구조화 출력 → 멀티에이전트 오케스트레이션** 이라는
요즘 AI 앱의 핵심 뼈대를, 완성된 미니 앱과 함께 손에 넣게 됩니다.

**대상:** 파이썬 기본 문법(변수·함수·반복문)만 아시면 충분합니다. AI를 코드로
다뤄본 적이 없어도 끝까지 따라올 수 있도록 설계했습니다.

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `command not found: uv` | 터미널을 닫았다가 다시 열어 보세요 |
| `GOOGLE_API_KEY를 찾을 수 없습니다` | `.env` 파일을 만들고 키를 넣으셨는지 확인 (5번) |

| 실행이 멈춘 것 같아요 | 무료 티어 분당 한도입니다. 자동으로 다시 시도하니 잠시 기다리세요 |
| 그 외 | [설치 가이드](docs/prework/02-install.md)의 문제 해결 절 |
