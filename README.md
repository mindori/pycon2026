# AI 가계부 배틀

> 영수증을 던지면 AI 둘이 내 지갑을 두고 싸운다 — PyCon Korea 2026 튜토리얼

**일시:** 2026년 8월 17일(월) 10:00–13:00
**대상:** 파이썬 기본 문법(변수·함수·반복문)만 아시면 충분합니다. AI를 코드로
다뤄본 적이 없어도 끝까지 따라올 수 있도록 설계했습니다.

## 이 튜토리얼에서 무엇을 만드나요

영수증 사진 한 장을 AI들의 열띤 토론으로 바꾸는 미니 앱을 직접 만듭니다.
진행은 세 단계입니다.

1. **본다** — Vision(멀티모달) LLM으로 영수증 사진을 읽어 `{항목·금액·카테고리}`
   데이터로 바꿉니다. Pydantic으로 **구조화 출력(Structured Output)** 을 강제해
   들쭉날쭉한 LLM 응답을 안정적인 함수처럼 다루는 법을 배웁니다.
2. **정리한다** — 추출한 내역을 카테고리별로 집계해 나만의 가계부를
   완성합니다.
3. **토론한다** — '절약파(자린고비 할머니)'와 '플렉스파(욜로 인플루언서)' 두
   AI 에이전트가 같은 가계부를 두고 정반대로 해석하며 토론합니다. 여기서
   페르소나 프롬프트 설계와, 초급자가 가장 자주 빠지는 **멀티에이전트 무한
   루프를 막는 종료 조건 설계**를 배웁니다. 마지막엔 판정관 AI가 토론을
   종합해 재무 건강 점수와 처방전을 내놓습니다.

수료 후 여러분은 **멀티모달 입력 → 구조화 출력 → 멀티에이전트
오케스트레이션**이라는 요즘 AI 앱의 핵심 뼈대를, 내 영수증을 넣으면 AI 둘이
토론하고 재무 진단을 내주는 완성된 미니 앱과 함께 손에 넣게 됩니다.

## 실행 방법

```bash
git clone <저장소 주소>
cd <저장소 폴더명>
uv sync
cp .env.example .env      # 발급받은 API 키를 붙여넣으세요
uv run python check_env.py   # 모두 ✅가 나오는지 확인
uv run pytest                 # 테스트가 통과하는지 확인 (선택)
uv run python main.py         # receipts/ 폴더의 샘플 영수증으로 실행
```
