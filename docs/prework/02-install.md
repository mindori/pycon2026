# 2. 설치하기

**당일 아침에 하지 마세요. 지금 하세요.**

당일 아침에는 25명이 동시에 같은 페이지를 열고, 같은 명령을 치고, 같은
와이파이로 패키지를 내려받습니다. 그러면 느려지거나 막힙니다. 지금 미리
설치해두면 당일에는 노트북을 열고 바로 실습을 시작할 수 있습니다.

아직 API 키가 없다면 [1. API 키 발급받기](01-api-key.md)를 먼저 진행해
주세요.

## 1) `uv` 설치하기

`uv`는 이 튜토리얼에서 쓰는 파이썬 패키지·프로젝트 관리 도구입니다. 운영체제에
맞는 명령을 터미널에 입력하세요.

### macOS / Linux

먼저 터미널을 엽니다.

- **macOS**: `Cmd + Space`를 눌러 검색창을 연 뒤 "터미널"이라고 입력하고
  Enter를 누릅니다.
- **Linux**: `Ctrl + Alt + T`를 누릅니다. (배포판에 따라 다를 수 있습니다.
  안 되면 앱 목록에서 "터미널"을 찾아 실행하세요.)

터미널이 열리면 다음을 입력하고 Enter를 누릅니다.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Windows

시작 메뉴를 열고(키보드의 Windows 키를 누르면 됩니다) "PowerShell"이라고
입력한 뒤 검색 결과에서 "Windows PowerShell"을 클릭해 실행합니다.

PowerShell 창이 열리면 다음을 입력하고 Enter를 누릅니다.

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

설치가 끝나면 **터미널(또는 PowerShell)을 한 번 완전히 닫았다가 다시
여세요.** 그래야 `uv` 명령이 인식됩니다.

설치가 잘 됐는지는 아래 명령으로 확인합니다. 버전 번호가 출력되면 성공입니다.

```bash
uv --version
```

## 2) 저장소 내려받기

저장소 주소를 안내받으셨다면 다음 명령으로 내려받습니다.

```bash
git clone https://github.com/mindori/pycon2026.git
cd pycon2026
```

`git`이 없다면 GitHub 페이지의 초록색 "Code" 버튼 → "Download ZIP"으로 받아서
압축을 풀어도 됩니다. 이 경우 폴더 이름이 `pycon2026`이 아니라 **`pycon2026-main`**
으로 만들어집니다.

```bash
cd pycon2026-main
```

## 3) 의존성 설치

저장소 폴더 안에서 다음 명령을 실행합니다. 필요한 패키지를 자동으로
내려받습니다. 인터넷 속도에 따라 1~2분 정도 걸립니다.

```bash
uv sync
```

### `unsupported operand type(s) for |` 라는 에러가 나요

코드 문제가 아니라 **가상환경이 깨진 것**입니다. 폴더 이름을 바꿨거나 다른 곳으로
옮겼을 때 생깁니다. `models.py`를 잘못 친 것처럼 보이지만 아닙니다.

```bash
rm -rf .venv
uv sync
```

이렇게 가상환경을 다시 만들면 해결됩니다.

## 4) `.env` 파일 준비

[API 키 발급 가이드](01-api-key.md)를 따라 `.env` 파일에 키를 넣어두지
않았다면 지금 진행합니다. **이미 키를 발급받아 복사해 두셨다면**
[키를 `.env`에 붙여넣는 단계](01-api-key.md#4-키를-복사해서-env-파일에-붙여넣기)만
다시 하시면 됩니다 — 키를 새로 만들 필요는 없습니다.

## 5) 환경 진단 실행

모든 준비가 끝났는지 아래 명령으로 확인합니다.

```bash
uv run python check_env.py
```

### 성공 예시

아래처럼 모든 줄이 ✅면 준비 완료입니다. 노트북을 덮고 당일 오전 10시에
뵙겠습니다.

```
==============================================
 PyCon 2026 AI 가계부 배틀 — 환경 진단
==============================================
✅ 파이썬 3.11
✅ uv 설치됨
✅ .env 파일에 GOOGLE_API_KEY(또는 GEMINI_API_KEY) 있음
✅ API 키가 실제로 동작함
✅ 모델(gemini-3.5-flash)이 응답함
----------------------------------------------
모두 통과했습니다. 당일에 뵙겠습니다!
```

### "한도에 걸렸습니다" 예시 — 이것도 통과입니다

마지막 줄이 아래처럼 ✅ 옆에 "분당 요청 한도" 안내가 붙어 나올 수 있습니다.
**이건 실패가 아닙니다.** 무료 티어는 1분에 보낼 수 있는 요청 수가 정해져
있는데, 다른 참가자와 같은 시간대에 점검하다 보면 잠깐 한도에 걸릴 수
있습니다. 키 자체는 이미 정상으로 확인된 상태이니, 1분 정도 뒤에 다시
실행하거나 그냥 넘어가도 됩니다.

```
==============================================
 PyCon 2026 AI 가계부 배틀 — 환경 진단
==============================================
✅ 파이썬 3.11
✅ uv 설치됨
✅ .env 파일에 GOOGLE_API_KEY(또는 GEMINI_API_KEY) 있음
✅ API 키가 실제로 동작함
✅ 모델(gemini-3.5-flash) 확인됨 — 지금은 분당 요청 한도에 걸려 있습니다. 키는 정상입니다 — 1분 정도 뒤에 다시 실행하거나 그대로 실습을 시작해도 됩니다.
----------------------------------------------
모두 통과했습니다. 당일에 뵙겠습니다!
```

### 실패 예시

❌가 하나라도 있으면 그 아래 `→`로 시작하는 줄에 다음 행동이 적혀 있습니다.
그대로 따라 하고 다시 `uv run python check_env.py`를 실행하세요.

```
==============================================
 PyCon 2026 AI 가계부 배틀 — 환경 진단
==============================================
✅ 파이썬 3.11
✅ uv 설치됨
❌ .env 파일에 GOOGLE_API_KEY(또는 GEMINI_API_KEY) 있음
   → .env.example을 .env로 복사하고 발급받은 키를 붙여넣으세요. (docs/prework/01-api-key.md 참고)
❌ API 키가 실제로 동작함
   → 위 항목을 먼저 해결한 뒤 다시 실행하세요.
❌ 모델(gemini-3.5-flash)이 응답함
   → 위 항목을 먼저 해결한 뒤 다시 실행하세요.
----------------------------------------------
❌ 항목을 해결한 뒤 다시 실행해 주세요.
   해결이 어려우면 8/16(일) 저녁 온라인 사전 점검에 참여해 주세요.
```

실습을 이어갈 수 있습니다. (데이터 요금이 걱정되신다면, 텍스트 요청 위주라
