# 1. API 키 준비하기

이 튜토리얼은 Google의 AI 모델(Gemini)을 코드에서 불러 씁니다. 그러려면
"API 키"라는 비밀번호 같은 문자열이 하나 필요합니다.

## 🔑 오늘 쓸 키는 강사가 보내드립니다

**여러분이 발급받지 않으셔도 됩니다.** 강사가 이 튜토리얼 전용 키를 만들어
**참가자 메일로 보내드립니다.** 비용도 강사가 부담합니다.

| 언제 | 무엇 |
|---|---|
| **8/16(일) 사전 점검 전후** | 등록하신 메일로 키가 발송됩니다 |
| **8/17(월) 수업 시작 전** | 못 받으신 분은 현장에서 메일 주소를 알려 주시면 바로 보내드립니다 |

메일 제목은 **"[PyCon 튜토리얼] AI 가계부 배틀 — 실습용 API 키"** 입니다.
스팸함도 한 번 확인해 주세요.

> 📌 **사전 준비에서 할 일이 하나 줄었습니다.** 예전 안내에는 "키를 직접
> 발급받으세요"가 있었지만 지금은 필요 없습니다. [설치 가이드](02-install.md)의
> `uv` 설치와 저장소 내려받기만 미리 해두시면 됩니다.

## 받은 키를 `.env` 파일에 넣기

1. 저장소를 아직 내려받지 않으셨다면 [설치 가이드](02-install.md)를 먼저
   진행하세요.

2. 저장소 안의 `.env.example` 파일을 복사해서 `.env`라는 새 파일을 만듭니다.

   **맥 · 리눅스**
   ```bash
   cp .env.example .env
   ```

   **윈도우 (PowerShell)**
   ```powershell
   copy .env.example .env
   ```

   (파일 탐색기에서 복사·붙여넣기 후 이름만 바꾸셔도 됩니다.)

3. `.env` 파일을 텍스트 편집기로 열면 아래처럼 되어 있습니다.

   ```
   GOOGLE_API_KEY=여기에_강사가_보낸_키를_붙여넣으세요
   ```

4. `여기에_강사가_보낸_키를_붙여넣으세요` 부분을 지우고, 메일로 받은 키로
   바꿔치기합니다. **앞뒤에 따옴표나 공백을 넣지 마세요.**

   ```
   GOOGLE_API_KEY=AQ.Ab8RN6............................
   ```

5. 파일을 저장합니다. 끝입니다.

> 온라인의 다른 Gemini 튜토리얼을 먼저 보셨다면 `GEMINI_API_KEY`라는 이름으로
> 안내하는 경우도 있습니다. 이 저장소는 두 이름을 모두 인식하니, 이미
> `GEMINI_API_KEY`로 설정하셨다면 그대로 두셔도 괜찮습니다.

## 확인은 이렇게

```bash
uv run python check_env.py
```

✅ 다섯 개가 나오면 준비 끝입니다. 자세한 화면은
[설치 가이드](02-install.md)에 있습니다.

## 이 키를 다룰 때

- **오늘 하루만 쓰는 임시 키입니다.** 튜토리얼이 끝나면 강사가 폐기합니다.
  집에서 계속 실습하시려면 아래 "직접 발급받기"를 보세요.
- **공개된 곳에 올리지 마세요.** 이 저장소의 `.gitignore`는 이미 `.env`를 커밋
  대상에서 제외하지만, 파일 이름을 다르게 저장하면 이 보호를 벗어납니다.
- **화면 공유나 스크린샷 조심하세요.** 질문하실 때 화면을 공유하게 되면
  `.env` 파일 창은 닫아두세요.
- 25명이 같은 키를 나눠 쓰므로 **가끔 응답이 느려집니다.** 혼자 돌리면 10초,
  다 같이 몰리면 20초쯤 걸립니다. 고장이 아닙니다.

## "잠깐 멈춤"은 고장이 아닙니다

여러 사람이 동시에 요청을 보내면 1분당 요청 한도에 걸릴 수 있습니다. 그럴 때
코드는 **자동으로 잠깐 기다렸다가 다시 시도**합니다. 화면이 몇 초간 멈춘 것처럼
보여도 당황하지 마세요.

## (부록) 내 키를 직접 발급받기

**오늘은 안 하셔도 됩니다.** 튜토리얼이 끝난 뒤 집에서 계속 해보고 싶을 때,
또는 강사 키가 안 올 때 쓰세요. **무료이고 신용카드 등록이 필요 없습니다.**

1. [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey) 접속
2. 평소 쓰시는 Google 계정으로 로그인
3. **"Create API key"** (또는 "API 키 만들기") 클릭
4. 만들어진 키를 복사해서 위 "받은 키를 `.env` 파일에 넣기" 4번 자리에 붙여넣기

> 결제 수단을 묻는 화면이 뜬다면 잘못된 페이지입니다. 위 주소를 다시 확인하세요.
>
> 새로 만든 키가 `AIza...`로 시작할 수도, `AQ....`로 시작할 수도 있습니다.
> **둘 다 정상입니다.** 발급 시기에 따라 형식이 다릅니다.
