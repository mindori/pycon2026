# 1. API 키 발급받기

이 튜토리얼은 Google의 AI 모델(Gemini)을 코드에서 불러 씁니다. 그러려면
"API 키"라는 비밀번호 같은 문자열이 하나 필요합니다. 아래를 그대로 따라오시면
5분이면 끝납니다.

**신용카드 등록은 필요 없습니다.** 이 튜토리얼에서 쓰는 무료 티어는 카드 정보를
요구하지 않습니다. 결제 수단을 묻는 화면이 뜬다면 잘못된 페이지에 들어온 것이니
아래 주소를 다시 확인해 주세요.

## 1) AI Studio 접속

브라우저에서 아래 주소로 들어갑니다.

[https://aistudio.google.com/apikey](https://aistudio.google.com/apikey)

## 2) Google 계정으로 로그인

평소 쓰시는 Google 계정(Gmail 계정)으로 로그인합니다. 계정이 없다면 새로
만드셔도 됩니다.

## 3) "Create API key" 클릭

로그인하면 화면에 **"Create API key"** (또는 "API 키 만들기") 버튼이 보입니다.
클릭하면 몇 초 안에 `AIza...`로 시작하는 긴 문자열이 만들어집니다. 이게 여러분의
API 키입니다.

## 4) 키를 복사해서 `.env` 파일에 붙여넣기

1. 생성된 키 옆의 복사 아이콘을 눌러 키를 복사합니다.
2. 저장소를 아직 내려받지 않으셨다면 [설치 가이드](02-install.md)를 먼저
   진행해 저장소를 내려받습니다.
3. 저장소 안의 `.env.example` 파일을 복사해서 `.env`라는 새 파일을 만듭니다.
   (파일 탐색기에서 복사·붙여넣기 후 이름만 바꾸셔도 됩니다.)
4. `.env` 파일을 텍스트 편집기로 열면 아래처럼 되어 있습니다.

   ```
   GOOGLE_API_KEY=여기에_발급받은_키를_붙여넣으세요
   ```

5. `여기에_발급받은_키를_붙여넣으세요` 부분을 지우고, 방금 복사한 키로
   바꿔치기합니다. 앞뒤에 따옴표나 공백을 넣지 마세요.

   ```
   GOOGLE_API_KEY=AIzaSy........................
   ```

6. 파일을 저장합니다. 끝입니다.

> 온라인의 다른 Gemini 튜토리얼을 먼저 보셨다면 `GEMINI_API_KEY`라는 이름으로
> 안내하는 경우도 있습니다. 이 저장소는 두 이름을 모두 인식하니, 이미
> `GEMINI_API_KEY`로 설정하셨다면 그대로 두셔도 괜찮습니다.

## 키는 비밀번호입니다 — 절대 공개하지 마세요

- **누구에게도 공유하지 마세요.** 이 키로 누구나 여러분의 이름으로 API를
  호출할 수 있습니다.
- **화면 공유나 스크린샷에 찍히지 않도록 주의하세요.** 튜토리얼 중 질문할 때
  화면을 공유하게 되면, `.env` 파일 창은 꼭 닫아두세요.
- **GitHub 등 공개 저장소에 절대 커밋하지 마세요.** 이 저장소의 `.gitignore`는
  이미 `.env` 파일을 커밋 대상에서 제외하도록 설정되어 있지만, 파일 이름을
  다르게 저장하면 이 보호를 벗어날 수 있으니 주의하세요.
- 실수로 키가 노출됐다면 AI Studio에서 해당 키를 즉시 삭제(revoke)하고 새로
  발급받으세요.

## 무료 티어의 "잠깐 멈춤"은 고장이 아닙니다

무료 티어에는 1분당 보낼 수 있는 요청 횟수 제한이 있습니다. 실습 중 AI 두
명이 여러 차례 대화를 주고받다 보면 이 한도에 걸릴 수 있습니다. 그럴 때 코드는
자동으로 잠깐 기다렸다가 다시 시도하도록 만들어져 있습니다. 화면이 몇 초간
멈춘 것처럼 보여도 당황하지 마세요 — 정상 동작입니다.

## 확인은 이렇게

키를 넣었으면 [설치 가이드(02-install.md)](02-install.md)의 안내대로
`check_env.py`를 실행해 키가 실제로 동작하는지 확인하세요.
