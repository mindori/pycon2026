# 0막 — 환경 점검과 첫 호출 (20분)

## 이번 막에서 할 일

내 노트북에서 AI를 처음으로 한 번 불러보고, 영수증 사진을 보여줍니다.

## 완성하면 이렇게 됩니다

영수증 사진 한 장을 던졌더니 AI가 이렇게 **줄글로** 답합니다.

```
영수증에 적힌 주요 내용과 항목, 금액 정보를 정리해 드립니다.

### **1. 가게 정보**
* **상호명:** 다이닝
* **주소:** 서울특별시 서초구 ○○○○ (교재에서 가렸습니다)
* **거래 일시:** 2026년 7월 25일 17:25:47

---

### **2. 구매 항목 및 금액**
* **아메리칸쿠키 (오리지널 다크초코)**
  * 수량: 1개
  * 금액: **3,800원**
* **아메리칸쿠키 (에스프레소 피칸)**
  * 수량: 1개
  * 금액: **3,800원**

---

### **3. 결제 금액**
* **합계:** **7,600원**
  * 공급가액: 6,910원
  * 부가세: 690원
* **결제 금액:** **7,600원**
* **결제 수단:** KB국민카드 (일시불)
```

문장은 매번 다릅니다. 표로 줄 때도 있고 목록으로 줄 때도 있습니다. **모양이 매번
다르다는 것이 오늘 1막의 출발점입니다.**

> 위 예시에서 주소와 대표자 이름은 교재에 싣지 않으려고 가렸습니다. 영수증에는
> 생각보다 많은 것이 적혀 있습니다. 본인 영수증을 쓰실 때 이 점을 기억해 주세요
> (자세한 안내는 [3막](03-토론한다.md) 도입부에 있습니다).

```

모두 통과했습니다. 당일에 뵙겠습니다!
```

이 경우 **기다리지 말고 그대로 다음 단계로 가세요.** 실습 코드에는 재시도가 들어
있어서 한도에 걸려도 알아서 넘깁니다.

❌가 있으면 그 줄 아래 `→`에 다음 할 일이 적혀 있습니다. 자주 나오는 것만
추리면 이렇습니다.

| ❌인 줄 | 할 일 |
|---|---|
| `uv 설치됨` | [설치 가이드](../prework/02-install.md)의 1)을 실행하고 **터미널을 껐다 켜세요** |
| `.env 파일에 …` | `.env.example`을 복사해 `.env`로 만들고 키를 붙여넣으세요 ([API 키 가이드](../prework/01-api-key.md)) |
| `API 키가 실제로 동작함` | 키 앞뒤에 따옴표·공백이 있는지 확인하세요. 그래도 안 되면 키를 새로 발급받으세요 |
| `모델(...)이 응답함` + `키가 거부되었습니다(401/403)` | 키가 잘못 붙여넣어졌습니다. `.env`를 다시 확인하세요 |
| `모델(...)이 응답함` + `404` | 모델이 사라진 경우입니다. **강사에게 알려 주세요** — 혼자 해결할 수 있는 문제가 아닙니다 |

### 4. AI를 처음으로 부릅니다

`main.py` 파일을 편집기로 엽니다. 완성된 코드가 들어 있을 텐데, **전부 지우고**
아래 다섯 줄로 바꿉니다.

`main.py`

```python
"""0막 — 환경 점검. 여기까지 되면 준비 끝입니다."""

from budget_battle import client

print(client.generate_text("한 문장으로 인사해 줘."))
```

> 원래 있던 `main.py`가 아까우신가요? 그대로 `steps/step5_judge.py`에 남아 있습니다.
> 오늘 4막이 끝나면 여러분 손으로 저것과 똑같은 파일을 다시 만들게 됩니다.

저장하고 실행합니다.

```bash
uv run python main.py
```

```
안녕하세요, 만나서 정말 반갑고 오늘 하루도 행복하게 보내시길 바랍니다!
```

방금 세 가지가 한꺼번에 일어났습니다.

1. `budget_battle/config.py`가 `.env`에서 API 키를 읽었습니다.
2. `budget_battle/client.py`가 Google 서버에 요청을 보냈습니다.
3. 답이 문자열로 돌아왔습니다.

`client.py`는 오늘 손대지 않습니다. 재시도·백오프·캐시 폴백이 들어 있는 안전장치라
현장 네트워크가 흔들려도 진도가 멈추지 않게 해 줍니다.

> **화면이 몇 초 멈춰도 고장이 아닙니다.** 무료 티어 분당 요청 한도에 걸리면
> `client.py`가 알아서 2초 → 4초 쉬었다가 다시 시도합니다. 10초 정도는 그냥
> 기다려 주세요.
>
> 세 번 다 실패하면 빨간 에러(트레이스백)가 뜹니다. 맨 아랫줄에 `ApiCallFailed`가
> 보이면 코드가 아니라 네트워크나 분당 한도 문제입니다. **1분 뒤 같은 명령을 그대로
> 다시 실행하세요.** (4막에서 완성할 `main.py`에는 이럴 때 트레이스백 대신 안내문을
> 띄우는 코드가 들어갑니다.)

### 5. 이번엔 영수증을 보여줍니다

`main.py`를 다시 **전부 지우고** 아래로 바꿉니다.

`main.py`

```python
"""0막 — 영수증을 자유 텍스트로 읽기.

이 결과를 코드로 쓰려면 어떻게 해야 할까요? 그게 1막의 주제입니다.
"""

from google.genai import types

from budget_battle import client, config

image_path = config.RECEIPTS_DIR / "sample_01.jpg"
part = types.Part.from_bytes(data=image_path.read_bytes(), mime_type="image/jpeg")

print(client.generate_text([part, "이 영수증에 뭐가 적혀 있어? 항목과 금액을 알려줘."]))
```

```bash
uv run python main.py
```

맨 위 "완성하면 이렇게 됩니다"의 그 줄글이 나옵니다.

`types.Part.from_bytes`가 이미지 바이트를 요청에 실어 보내는 부분입니다. 텍스트만
받던 모델에 **사진을 같이 넘긴 것**이 전부입니다. 이걸 멀티모달이라고 부릅니다.
