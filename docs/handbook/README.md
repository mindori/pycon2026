# 핸즈온 교재 — AI 가계부 배틀

PyCon Korea 2026 튜토리얼 · 2026년 8월 17일(월) 10:00–13:00

이 폴더가 오늘의 교재입니다. 강사 화면과 **따로** 읽으셔도 됩니다. 오히려 그러라고
만들었습니다. 진도가 밀렸을 때 손을 들지 않고 혼자 따라잡을 수 있는 것이 이 교재의
유일한 목적입니다.

## 오늘 만드는 것

영수증 사진을 넣으면 AI 둘이 내 소비를 두고 싸우고, 판정관이 점수를 매깁니다.

```

  다이닌 / 2026-07-25 / 7,600원

========================================
[내 가계부]
영수증 1장, 총 지출 7,600원
- 카페/간식: 7,600원 (100%)

========================================
[토론 시작]

<자린고비 할머니>
아이고 손주야, 내 젊을 적엔 7,600원이면 온 식구 일주일 치 쌀을 샀는디 ...

<YOLO 인플루언서>
아메리카노 한 잔과 달콤한 디저트가 주는 그 행복은 단순한 간식이 아니라 ...

========================================
[판정]

  2. 오늘 간식에 소비한 7,600원을 즉시 비상금 계좌로 이체하세요.
  3. '스트레스 해소를 위한 무료 대체 활동' 3가지를 메모장에 적어두세요.
```

## 이 교재를 쓰는 법

- 각 막 끝에 **✅ 체크포인트**가 있습니다. 화면에서 그게 확인되면 다음 막으로 가세요.
- 확인되지 않으면 그 아래 **막혔다면**을 그대로 실행하세요. 한 명이 막혔다고 24명이
  기다리지 않습니다. 복구하고 합류하는 것이 정상 경로입니다.
- 코드 블록은 **복사해 붙여넣어도 됩니다.** 손으로 치는 편이 오래 남지만, 시간에
  쫓기면 붙여넣고 한 줄씩 읽는 것도 충분한 학습입니다.
- 교재의 코드 블록은 저장소의 완성본과 글자 단위로 같습니다. 오타로 무너졌을 때
  블록을 통째로 다시 붙여넣으면 그 파일은 원래대로 돌아옵니다.

## 저장소에는 완성본이 이미 들어 있습니다

내려받은 저장소의 `budget_battle/` 폴더에는 오늘 만들 파일들이 **완성된 채로** 들어
있습니다. 지우고 다시 쓰라고 넣어둔 답안지입니다.

| 파일 | 오늘 |
|---|---|
| `budget_battle/config.py` | **손대지 않습니다.** 키 로딩·모델 ID·상수 |
| `budget_battle/client.py` | **손대지 않습니다.** 재시도·백오프·캐시 폴백 |
| `budget_battle/models.py` | 1막·3막·4막에서 나눠 씁니다 |
| `budget_battle/vision.py` | 1막에서 씁니다 |
| `budget_battle/ledger.py` | 2막에서 씁니다 |
| `budget_battle/personas.py` | 3막에서 씁니다 |
| `budget_battle/debate.py` | 3막에서 씁니다 |
| `budget_battle/judge.py` | 4막에서 씁니다 |
| `main.py` | 매 막마다 통째로 갈아엎습니다 |
| `app.py` | 강사 제공. 4막에서 실행만 합니다 |

`client.py` 두 가지만 기억하세요. **재시도**(API가 실패하면 알아서 몇 초 쉬었다가
다시 부릅니다)와 **캐시 폴백**(그래도 안 되면 `cache/`에 미리 뽑아둔 영수증 결과를
꺼내 씁니다). 백오프를 직접 짜는 건 오늘의 학습 목표가 아니고, 이게 있어야 현장
와이파이가 흔들려도 진도가 멈추지 않습니다.

## 막혔을 때

각 막의 마지막 상태가 `steps/` 폴더에 그대로 들어 있습니다. `main.py`로 **복사한 뒤**
실행하세요.

> **윈도우 사용자:** 아래 `cp` 명령은 PowerShell에서 그대로 동작합니다.
> cmd를 쓰신다면 `cp` 를 `copy` 로 바꾸세요.

| 여기서 막혔다면 | 이 명령 |
|---|---|
| 0막 (첫 호출) | `cp steps/step0_hello.py main.py` |
| 0막 (자유 텍스트) | `cp steps/step1_freetext.py main.py` |
| 1막 | `cp steps/step2_structured.py main.py` |
| 2막 | `cp steps/step3_ledger.py main.py` |
| 3막 | `cp steps/step4_debate.py main.py` |
| 4막 | `cp steps/step5_judge.py main.py` |

복사한 다음 실행합니다.

```bash
uv run python main.py
```

> ⚠️ `uv run python steps/step2_structured.py`처럼 **`steps/` 안의 파일을 직접
> 실행하면 동작하지 않습니다.** `steps/`는 프로젝트 루트가 아니라서 파이썬이
> `budget_battle` 패키지를 찾지 못하고 `ModuleNotFoundError`가 납니다. 반드시
> `main.py`로 복사한 뒤 실행하세요.

Windows PowerShell에서는 `cp` 대신 `copy`를 써도 됩니다(`cp`도 대개 동작합니다).

```powershell
copy steps\step2_structured.py main.py
```

### `budget_battle/` 안의 파일이 깨졌다면

`git clone`으로 내려받으셨다면 이 한 줄이 가장 빠릅니다. 오늘 고친 모듈이 전부
원래대로 돌아갑니다.

```bash
git restore budget_battle/
```

ZIP으로 받으셨다면 `git restore`가 안 됩니다. 해당 막 문서의 코드 블록을 통째로
다시 붙여넣으세요. 블록이 곧 원본입니다.

> **순서가 중요합니다.** `main.py`만 스냅샷으로 되돌려도 `budget_battle/` 안의
> 파일이 반쯤 치다 만 상태면 스냅샷도 그대로 깨집니다. 예를 들어 `ledger.py`가
> 미완성이면 3막 스냅샷(`step4_debate.py`)도 실행되지 않습니다.
> **모듈부터 되돌리고 스냅샷을 복사하세요.**

## 자주 나오는 상황 네 가지

**1. 화면이 몇 초 멈춰 있어요 — 고장이 아닙니다.**
무료 티어에는 분당 요청 횟수 제한이 있습니다. 한도에 걸리면 코드가 **알아서 잠깐
기다렸다가 다시 시도합니다.** 2초 → 4초 순으로 쉬었다 재시도하니 10초 정도는
그냥 기다려 주세요.

세 번 다 실패하면 빨간 에러(트레이스백)가 뜹니다. 맨 아랫줄에 `ApiCallFailed`가
보이면 코드가 아니라 네트워크나 분당 한도 문제입니다. 1분 뒤 같은 명령을 그대로
다시 실행하세요. (4막에서 완성할 `main.py`에는 이럴 때 트레이스백 대신 안내문을
띄우는 코드가 들어갑니다.)

**2. 아이폰 사진(HEIC)은 안 올라갑니다.**
`jpg`, `jpeg`, `png`, `webp`만 지원합니다. 아이폰 사진은 미리보기 앱에서 JPEG로
내보내거나, 카메라 설정 → 포맷 → "높은 호환성"으로 바꿔 다시 찍으세요.

**3. `GOOGLE_API_KEY를 찾을 수 없습니다`**
`.env` 파일이 없거나 키가 비어 있습니다. 강사가 메일로 보내드린 키를
[사전 준비 문서](../prework/01-api-key.md)대로 넣으세요. 키 앞뒤에 따옴표나
공백이 있으면 안 됩니다. **메일을 못 받으셨으면 손 드세요 — 바로 보내드립니다.**

**4. Streamlit 앱은 `.env` 변경을 못 읽습니다.**
앱을 띄운 뒤에 `.env`를 고쳤다면 **서버를 껐다 켜야** 합니다. 자세한 건
[4막](04-판정.md)에 있습니다.
